# HackerRank Solutions – Problem Solving (C++)

This repository contains my solutions to **HackerRank DSA problems** using **C++**.

## 📝 Problem: Counting Valleys
- **Category**: Warm-up
- **Link**: [Counting Valleys on HackerRank](https://www.hackerrank.com/challenges/counting-valleys/problem?isFullScreen=true)
- **Solution**: [`counting_valleys.cpp`](./counting_valleys.cpp)

## 📌 Approach
- Track sea level using a counter.
- Count a valley every time we step **up to sea level** from below.
