## 📝 Problem: Array-left-rotation
- **Category**: Warm-up
- **Link**: [Counting Valleys on HackerRank](https://www.hackerrank.com/challenges/array-left-rotation/problem?isFullScreen=true)
- **Solution**: [`array-left-rotation`](./array-left-rotation.cpp)

## 📌 Approach
- calculate the new index after rotation
- replace the value of the new array at index to the value of the original array at the current iteration
